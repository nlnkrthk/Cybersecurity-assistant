KEY IMPROVEMENTS
================================================================================

From Monolithic to Modular:
  Before: 1 script (360 lines) with all logic
  After:  1 orchestration (200 lines) + 5 modules (800 lines)

Benefits:
  - Reusability: Modules can be imported anywhere
  - Testability: Each function can be unit tested
  - Maintainability: Single responsibility principle
  - Extensibility: Easy to add new steps
  - Debuggability: Extensive logging
  - Performance: 28x better memory efficiency
  - Scalability: PySpark handles large datasets

Architecture Pattern:
  Orchestration script (lightweight)
      │
      ├─→ loader.py        (Load & verify)
      ├─→ cleaner.py       (Clean & normalize)
      ├─→ sampler.py       (Stratified sampling)
      ├─→ text_builder.py  (Generate text)
      └─→ validator.py     (Verify output)
           │
           └─→ incidents_100k.parquet (~100K rows)

1. PREPARE RAW DATA

   Files needed:
   - Monday-WorkingHours.pcap_ISCX.csv
   - Tuesday-WorkingHours.pcap_ISCX.csv
   - Wednesday-workingHours.pcap_ISCX.csv
   - Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv
   - Thursday-WorkingHours-Afternoon-Infilteration.pcap_ISCX.csv
   - Friday-WorkingHours-Morning.pcap_ISCX.csv
   - Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv
   - Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv

2. RUN DATA PREPARATION
   $ python scripts/data/prepare_incident_data.py

   Output:
   - data/processed/incidents_100k.parquet (~30-50 MB)
   - data/logs/data_prep_YYYYMMDD_HHMMSS.log (detailed logs)

   Time: ~5-10 minutes

3. BUILD SEARCH INDEXES
   $ python scripts/indexing/build_search_indexes.py

   Output:
   - data/processed/bm25_index.pkl
   - data/processed/chroma/ (vector database)

   Time: ~2-5 minutes

4. RUN INTERACTIVE SEARCH
   $ python scripts/search/interactive_hybrid_search.py
   or
   $ python scripts/search/interactive_rag.py

================================================================================
DATA PIPELINE FLOW
================================================================================

Input: 8 CSV files (2.8M rows)
   ↓
Load (loader.py)
   ↓
Clean: normalize, cast, handle null/inf (cleaner.py)
   ↓
Standardize: labels, columns (cleaner.py)
   ↓
Deduplicate (cleaner.py)
   ↓
Analyze: label distribution (sampler.py)
   ↓
Stratified Sample: ~100K rows (sampler.py)
   ↓
Convert to Pandas (final ~100K only)
   ↓
Assign incident IDs: "INC-000001", etc.
   ↓
Generate incident_text (text_builder.py)
   ↓
Save to Parquet (pandas)
   ↓
Verify: schema, counts, distribution (validator.py)
   ↓
Output: incidents_100k.parquet (~30-50 MB)
